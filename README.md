## About This Portfolio

This portfolio demonstrates my interest in technical writing, documentation, and Python-based automation.

It includes a user guide and a Python tool that checks Markdown documentation for common quality issues.

## Project Structure

- `docs/` – Contains the technical writing sample.
- `scripts/` – Contains the Python documentation checker.

## Writing Sample

**How to Book an Appointment**

A user guide explaining the steps to book an appointment through the Shree Balaji Multispeciality Hospital Website.

## Python Project: Documentation Quality Checker

A Python script that checks Markdown files for:

- Missing main headings.
- Extra spaces at the end of lines.
- Unfinished TODO markers.
- Broken local links.

## How to Run

Make sure Python is installed.

Open the terminal in the project folder and run:

```bash
python scripts/check_docs.py
```
